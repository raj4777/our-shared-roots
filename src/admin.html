Where is my data?

In the Firestore console you mainly see short fields such as title, revision, and the email lists. The family tree itself is not a list of documents. It is stored as one long string field called payloadJson on the document archives/familytree. Open that document, then open the payloadJson field to see (or copy) the people, families, and tree data. The change log lives in a second document, archives/familytree_log, in the changeLogJson string field. After you move the log, those two fields are the whole archive.

Download a readable JSON backup

This file is a pretty-printed copy of the tree (the same JSON that is stored inside payloadJson) plus the change log. It is easier to read than the single-line string in the Firestore console.
